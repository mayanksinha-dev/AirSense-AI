# 🌍 AirSense AI

### AI-Powered Air Quality Prediction Platform

AirSense AI is a premium machine learning web application that predicts air quality levels using environmental and pollution indicators. Built with Flask, Scikit-Learn, Glassmorphism UI, GSAP animations, and modern web technologies.

---

## 🚀 Features

✨ Air Quality Classification

📊 Real-Time Environmental Analysis

🧠 Machine Learning Powered Predictions

🌫️ Pollution Monitoring Dashboard

🎨 Apple-Inspired Glassmorphism UI

⚡ GSAP Smooth Animations

📱 Fully Responsive Design

🔍 Pollution Parameter Insights

## ⚙️ Installation

Clone the repository:

```bash
git clone https://github.com/mayanksinha-dev/AirSense-AI.git
cd AirSense-AI
```

Install dependencies:

```bash
pip install -r requirements.txt
```

Run the application:

```bash
python app.py
```

Open:

```text
http://127.0.0.1:5000
```
